# Chandima Pasan Perera — Portfolio Website

A responsive personal software engineering portfolio built with HTML, CSS and JavaScript.

## Files
- `index.html` — website content
- `style.css` — modern responsive styling
- `script.js` — navigation and reveal animations
- `Chandima_Pasan_Perera_CV.docx` — downloadable CV

## Publish FREE with GitHub Pages

1. Sign in to GitHub.
2. Create a new PUBLIC repository named exactly:
   `NCPPERERA.github.io`
3. Upload all files from this folder to the root of that repository.
4. Commit the files.
5. Open the repository and go to:
   **Settings → Pages**
6. Under **Build and deployment**, choose:
   **Deploy from a branch**
7. Select:
   **Branch: main**
   **Folder: / (root)**
8. Save.
9. After GitHub finishes deploying, your portfolio should be available at:
   `https://NCPPERERA.github.io`

## Before publishing
